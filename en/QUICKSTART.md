# Quick start

Open the sample, play through a short story, and then create your own project.

## Before you start

Purchases and installation will be handled through official stores. See [store availability](DEVELOPMENT.md#stores) for the current status. This website does not distribute executable files.

If you have a development build, follow its launch instructions. The current build uses names such as `maker.exe`; keep the matching `player.exe` beside it to export games. Check your build's instructions for supported operating systems and executable names. You do not need Go or a C compiler to run the editor or an exported game.

If you received a game ZIP, see [Play and export](PLAY_AND_EXPORT.md).

## Play the sample

1. Choose **Sample** to open **The Dark Lighthouse**.
2. Choose **Save** and select a project folder.
3. In **Scenes and actions**, inspect the text and choices. After editing, choose **Apply**, then **Save**.
4. Run **Validate** to check references and branches.
5. Open **Preview** and try the choices, checks, combat, and endings.
6. Choose **Export**, then select the play mode and output folder.

## Start a blank project

Choose **New project**. Set the title and content version in the **Project** tab, then save. An unfinished draft can be saved, but preview and export require a valid starting scene and a path to an ending.

For a quick start, choose a narrative, d20, or combat component in **Components**. Review the proposed addition before confirming. The entire addition can be undone in one step.

If the project already has a starting scene, added scenes are not connected automatically. Connect them in **Scenes and actions**. See [Component templates](TEMPLATES.md) for details and limitations.

## Apply and save

**Apply** updates the project currently being edited. Choose **Save** as well to write changes to files. Use **↶ / ↷** to undo or redo edits.

Use **Open** and select a project folder to load an existing project. Use **Save to another folder** to work on a separate copy.
