# Download the demo

Open a sample, change a scene and its choices, and play through the result. Try the **Narrafield Studio** creation workflow on your own computer.

{% include demo-download.html %}

## Start after downloading

1. Download the ZIP and **extract all files into the same folder**. Do not run the application from inside the archive.
2. Run **`maker.exe`**. No installer or development tools are required.
3. Choose **Start sample** on the launch screen to open The Dark Lighthouse. **Harbor Guild sample** combines several features in one project.
4. Choose **Save** to select your own project folder, then edit scenes and choices.
5. Use **Validate → Preview** to try the result. Keep the matching `player.exe` beside the editor to export games.

Continue with [Quick start](QUICKSTART.md) or find a specific feature in the [editor menu guide](EDITOR.md).

## What you can try

- Open a sample or choose **New project** to organize your world, characters, and places.
- Connect scenes, choices, rules, and checks, then play them in the preview.
- Save your project and try exporting a standalone game.

The ZIP includes the editor, player, server and operator tools, command-line utilities, and third-party license notices. Start by running `maker.exe`.

## Before you begin

This is a **development alpha**. It does not represent a finished store release or verified store integration. The executables are not code-signed, so your environment may display an unknown-publisher notice. Keep separate backups of important projects.

The demo uses runtime compatibility version **{{ site.data.demo.version }}**. Games and saves from older versions may be incompatible. Open a copy of your source project and export it again with this demo's player. Some menu layouts may differ from the detailed guides and screenshots.

Purchases and installation of the full product will be handled through official stores. See [Current capabilities](DEVELOPMENT.md) and [Troubleshooting](TROUBLESHOOTING.md) for more information.
