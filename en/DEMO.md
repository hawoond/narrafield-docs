# Download the demo

Open a sample, change a scene and its choices, and play through the result. It is a quick way to learn how to make a game with **Narrafield Studio**.

{% include demo-download.html %}

## Run the demo

1. Download the ZIP and **extract all files into the same folder**. Do not run the application from inside the archive.
2. Run **`maker.exe`**. No installer or development tools are required.
3. Open **Starter Templates** on the launcher and choose **A Small Errand** or **The Dark Lighthouse**. **The Harbor Guild Contract** combines several features in one project.
4. Choose **Save** to select your own project folder, then edit scenes and choices.
5. Use **Validate → Play** to try the result. Keep the matching `player.exe` beside the editor to export games.

Continue with [Quick start](QUICKSTART.md) or find a specific feature in the [editor menu guide](EDITOR.md).

## What you can try

- Open a sample or choose **New project** to organize your world, characters, and places.
- Connect scenes, choices, rules, and checks, then play them in the preview.
- Save your project and try exporting a standalone game.

The ZIP includes the editor, player, server and operator tools, command-line utilities, and third-party license notices. Start by running `maker.exe`.

## Before you begin

This is a **development alpha**. Some features are still in development, and store integrations still need testing. The executables are not code-signed, so your environment may display an unknown-publisher notice. Keep separate backups of important projects.

The demo’s game runtime is version **{{ site.data.demo.version }}**. Games and saves from older versions may be incompatible. Open a copy of your source project and export it again with this demo's player. Guide menus and images have been updated for this version.

Purchases and installation of the full product will be handled through official stores. See [Current capabilities](DEVELOPMENT.md) and [Troubleshooting](TROUBLESHOOTING.md) for more information.
